NexShift

Migrate your legacy .NET Framework repositories to modern .NET — automatically.
Point NexShift at any GitHub repo and get a full analysis of deprecated dependencies, a migration score, and (soon) an automatically migrated codebase ready to download.
Features

Detects .NET Framework version across all project files
Lists all NuGet packages with deprecation status and suggested replacements
Calculates a Migration Score (0–100)
Migrates code automatically using Roslyn + AI (coming soon)

Stack
.NET 10 · PostgreSQL · Octokit.NET · Roslyn · OpenAI
